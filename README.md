# TGNO-lab1
Данный проект представляет собой реализацию биграммной языковой модели на Python, без использования специализированных библиотек.

Источник данных: https://llibre.ru/books/23982/download/txt

Для запуска скрипта поместите файл metro-2033.txt в одну директорию со скриптом и выполните main.py

Нормализация:Весь текст приводится к нижнему регистру.
Токенизация: Используется регулярное выражение r'[а-яёa-z0-9]+(?:-[а-яёa-z0-9]+)*' для извлечения слов (включая слова с дефисом, например, "кто-то").
Обработка знаков препинания: Знаки препинания удаляются.
Обоснование: Если сделать знаки препинания отдельными токенами, размер словаря  неоправданно возрастет, а матрица биграмм станет крайне разреженной (много нулевых вероятностей). Поскольку цель модели — предсказывать следующее слово, а не пунктуацию, их удаление повышает качество оценки лексических последовательностей и снижает вычислительные затраты.
Статистика: Скрипт выводит общее число токенов, размер словаря (уникальных слов) и 20 самых частых слов.
Разделение данных: Последние 10% текста откладываются в тестовую выборку. Модель видит только первые 90% при обучении (fit), что обеспечивает честную оценку обобщающей способности.

Отсутствует сглаживание (любая новая комбинация слов обрушивает вероятность предложения в ноль.)
