# TGNO-lab1
Данный проект представляет собой реализацию биграммной языковой модели на Python, без использования специализированных библиотек.

Источник данных: https://llibre.ru/books/23982/download/txt

Для запуска скрипта поместите файл metro-2033.txt в одну директорию со скриптом и выполните main.py

ЧТО СДЕЛАНО:

1.Предобработка текста:

-Нормализация: Весь текст приводится к нижнему регистру.

-Токенизация: Используется регулярное выражение r'[а-яёa-z0-9]+(?:-[а-яёa-z0-9]+)*'. Оно позволяет извлекать слова, сохраняя слова с дефисом (например, «кто-то», «из-за»).

-Удаление пунктуации: Знаки препинания полностью удаляются.
Обоснование: Если сделать знаки препинания отдельными токенами, размер словаря неоправданно возрастет, а матрица биграмм станет крайне разреженной (появится много нулевых вероятностей). Поскольку цель модели — предсказывать следующее слово, а не пунктуацию, их удаление повышает качество оценки лексических последовательностей и снижает вычислительные затраты.

-Статистика: Скрипт выводит общее число токенов, размер словаря (уникальных слов) и 20 самых частых слов.

2.Разделение данных: Последние 10% текста откладываются в тестовую выборку. Модель обучается (fit) только на первых 90%, что обеспечивает честную оценку обобщающей способности.

3.Реализация модели (BigramLM):
-Написан класс биграммной языковой модели.
-Реализовано сглаживание Лапласа (параметр alpha) для борьбы с проблемой нулевых вероятностей.
-Добавлена функция генерации текста с поддержкой температуры (temperature) для управления случайностью и разнообразием выдаваемых слов.

4.Проведение экспериментов:
-Генерация текста с разными стартовыми словами и температурами.

-Сравнение логарифмического правдоподобия (logprob) для связного текста и текста с перемешанными словами.

-Оценка качества модели через метрику перплексии на отложенной тестовой выборке при разных значениях параметра сглаживания (alpha).

ЧТО ПОЛУЧИЛОСь:

1.Успешная токенизация и сбор статистики: Скрипт корректно обрабатывает русский текст, считая частотности и формируя словарь без мусорных символов.

2.Различение связного и хаотичного текста: Модель корректно присваивает более высокое правдоподобие (больший log P) связным фрагментам из тестовой выборки по сравнению с перемешанными. При использовании сглаживания (alpha=0.1) модель уверенно отличает реальные биграммы от случайных наборов слов.

3.Управление разнообразием через температуру:
При T=0.5 модель генерирует более предсказуемый, "жадный" текст.
При T=2.0 генерация становится более хаотичной и разнообразной, модель чаще выбирает редкие слова.

4.Оценка перплексии: Удалось посчитать перплексию на тестовой выборке. Экспериментально подтверждено, что меньшее значение сглаживания дает лучшую (меньшую) перплексию на данном корпусе.
ПЕРПЛЕКСИЯ НА ТЕСТОВОЙ ВЫБОРКЕ

При a=  1.000  Перплексия =  14081.75
При a=  0.100  Перплексия =  8000.15
При a=  0.010  Перплексия = 5987.87

ЧТО НЕ ПОЛУЧИЛОСь:

1. Генерация ломается без сглаживания.
2. Генерируется случайные предложения.( модель не может согласовать род, число или падеж слова с подлежащим, предложения получаются не осмысленными)
